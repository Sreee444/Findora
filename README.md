# 🔍 Findora - Lost & Found Community Platform

A modern, full-stack web application designed to help people reunite with their lost belongings through community collaboration.

> 📚 **Looking for deep technical architecture & interview defense?**  
> Check out the [Complete Architecture, Tech Tradeoffs & Interview Guide](PROJECT_ARCHITECTURE_AND_INTERVIEW_GUIDE.md).

## 🌟 Website Features

### 🔐 Authentication System
- User registration with email verification
- Secure login/logout functionality
- Admin panel for user management
- JWT-based authentication
- Password reset functionality

### 📍 Lost & Found Management
- Report Lost Items: Post detailed descriptions with photos and location
- Report Found Items: Help others by posting items you've discovered
- Smart Search: Filter by category, location, date, and keywords
- Status Tracking: Monitor the progress of your reports
- Location Integration: Map-based location selection and display

### 🔔 Notification System
- Real-time in-app notifications
- Email notifications for registration
- Match alerts when similar items are posted
- Notification management (mark as read, delete)

### 📊 User Dashboard
- Personal history with statistics
- Item management (edit, delete, mark as found)
- Profile management
- Activity tracking and analytics

### 🎨 Modern Design
- Responsive design for all devices
- Dark/Light mode toggle
- Handcrafted modern UI with Vanilla CSS & animations
- Interactive maps with Leaflet
- Mobile-first approach

## 🚀 Quick Start

### 1. Frontend (Pure HTML, CSS & Vanilla JS)
- Double-click `open-website.bat` or open `index.html` directly in your browser.
- No build tools, bundlers, or dependencies required!

### 2. Backend (Node.js & Express)
- Run `start-backend.bat` or:
  ```bash
  npm start
  ```
  *(or `cd backend && npm start`)*
